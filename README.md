🌸 HINATA WhatsApp Bot

HINATA is a feature-rich WhatsApp bot built with Node.js and Baileys.

Features

- Group management and administration
- Group protection and anti-spam tools
- Media search and download commands
- Stickers and image tools
- Games and interactive features
- Events and entertainment commands
- Arabic command system
