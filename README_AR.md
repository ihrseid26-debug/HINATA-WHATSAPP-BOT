# 🌸 HINATA — الإصدار التأسيسي 0.1.0

هذا مشروع جديد مستقل. لا يحتوي على أي ملفات من مشاريع سابقة.

## ما يعمل في هذه النسخة

- ربط WhatsApp باستخدام Pairing Code، مع حفظ الجلسة في `sessions/main`.
- استقبال أوامر تبدأ بالنقطة `.`.
- تجاهل المحادثات الخاصة افتراضيًا والعمل في المجموعات فقط.
- الرد مقتبسًا على رسالة الأمر.
- إضافة تفاعل Emoji إلى رسالة الأمر بعد نجاح التنفيذ.
- `.ping` و`.منيو` و`.مود ادمن` و`.مود اعضاء` و`.زخرفة` و`.منشن` (بالرد على رسالة).
- حفظ وضع المجموعة في ملف JSON.
- إعادة الاتصال تلقائيًا بعد الانقطاع غير الناتج عن تسجيل الخروج.
- فحص JavaScript واختبارات لوحدات تحليل النصوص.

## المتطلبات

- Node.js 20 أو أحدث. الأفضل استخدام إصدار LTS مثبت لديك في Termux.
- اتصال إنترنت أثناء تثبيت الحزم والربط.

## التشغيل في Termux

```bash
cd ~/HINATA
cp .env.example .env
npm install
npm run check
npm test
npm start
```

أدخل رقم واتساب برمز الدولة، أرقامًا فقط ومن دون `+` أو مسافات. أدخل رمز الربط من واتساب > الأجهزة المرتبطة > ربط جهاز > الربط برقم الهاتف.

## ملاحظات مهمة

- لا تشارك مجلد `sessions` أو ملف `.env` مع أحد؛ يحتويان بيانات حساسة.
- عند تفعيل `.مود ادمن` لن ينفذ البوت أوامر الأعضاء غير المشرفين. إعداد المجموعة محفوظ محليًا.
- هذا الإصدار لا يدّعي وجود 1500 أمر. سنضيف الأوامر بعد اكتمال اختبار كل وحدة.
- لا يمكن ضمان زمن 50ms؛ زمن الشبكة وواتساب والجهاز خارج سيطرة البرنامج. أمر `.ping` يعرض زمن المعالجة المحلية فقط.
- الأزرار التفاعلية المتقدمة، إدارة البوتات الفرعية، الحماية المتقدمة، والبحث عن الأغاني/الفيديو/الصور لم تُعلن كميزات جاهزة بعد؛ تُضاف كوحدات لاحقة بعد اختبارها على نسخة Baileys المثبتة.

## أوامر النسخة الحالية

| الأمر | الوظيفة |
|---|---|
| `.ping` | اختبار محلي |
| `.منيو` | عرض الأوامر المتاحة |
| `.مود ادمن` | تقييد الأوامر على مشرفي المجموعة |
| `.مود اعضاء` | السماح لجميع الأعضاء |
| `.زخرفة النص` | زخرفة/تأطير النص |
| `.منشن` | ذكر صاحب الرسالة التي ترد عليها |
